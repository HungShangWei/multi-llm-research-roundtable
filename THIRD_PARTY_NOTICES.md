## HTML named character references in `lib/evidence.mjs`

**What it is.** The `entities` constant on line 11 of `lib/evidence.mjs` is a JSON object with 2,125 entries that map HTML named character reference names (without the trailing semicolon) to their Unicode characters. `decodeEntities()` uses it to turn HTML entities into text during source checks. This notice concerns only that mapping data.

**Recorded origin.** Line 10 of `lib/evidence.mjs` reads: "Named HTML5 entities; exported from Python standard-library html.entities, no runtime dependency." The Python version, date and method of that export were not recorded.

**Upstream chain.**

1. Python standard library, `html.entities.html5` (source file `Lib/html/entities.py`). Python's documentation describes it as "A dictionary that maps HTML5 named character references to the equivalent Unicode character(s)" and notes that "the trailing semicolon is included in the name (e.g. 'gt;'), however some of the names are accepted by the standard even without the semicolon: in this case the name is present with and without the ';'."
2. The WHATWG HTML Standard. In the CPython `3.13` branch, the comment above that dictionary says it was "Generated by Tools/build/parse_html5_entities.py from https://html.spec.whatwg.org/entities.json and https://html.spec.whatwg.org/multipage/named-characters.html."

**Changes relative to Python's dictionary** (the brief summary of changes that clause 3 of the PSF License Agreement asks for): trailing semicolons were removed from the names; names that Python lists both with and without a semicolon were merged into one key, since both forms carry the same value; the result was written as a JSON object literal inside a JavaScript module. No character values were changed.

**Comparison made for this snapshot.** On 2026-10-19 (UTC), the constant was parsed as JSON text, without running project code, and compared with `{name.rstrip(';'): value for name, value in html5.items()}` from:

- the Python 3.10.12 standard library in the preparation environment — identical;
- `Lib/html/entities.py` from the CPython `3.13` branch, retrieved 2026-10-19 18:02 UTC and parsed without being executed — identical.

In both, `html5` has 2,231 entries that collapse to the same 2,125 names, and no name's forms with and without a semicolon disagree. This shows that the data match. It does not identify which Python version or date was used for the original export.
